ReconRaptorAI

A focused Bash workflow for approved security testing. Discover assets, collect URLs, analyze JavaScript, validate high-signal leads, and leave the result folder ready for review.

Install View source
quick start git clone https://github.com/Zuri09/ReconRaptor.git && cd ReconRaptor && ./install.sh --with-ollama

Built for signal

Recon output you can actually move through.

DISC

Discovery pipeline

Subdomains, DNS resolution, live hosts, archived URLs (waybackurls + gau), crawled URLs, JavaScript, and JSON files land in predictable folders.

JS

JavaScript analysis

Downloads live JavaScript, scans with Gitleaks, separates generic key candidates from higher-confidence leaks, and stores every match redacted.

VAL

Focused validators

Actively confirms exposed files, open redirects, CORS (including null-origin), GraphQL, cloud storage, TLS, and takeover signals with evidence-first output.

AI

Local or cloud triage

Uses Ollama, OpenAI, DeepSeek, or offline rules to group leads, rank likely impact, and write a readable review path.

SAFE

Privacy-first output

Secrets are stored as a prefix, length, and SHA-256 hash instead of the raw value. Raw HTTP evidence is pruned by default, and only sanitized context reaches any cloud model.

SCOPE

Stay in-scope

Drop out-of-scope subdomains with a regex exclude file before any probing starts, and tune parallelism, timeouts, and Nuclei tags to fit the engagement.

Install

Clone, install tools, scan an approved target.

Use Ollama for local AI triage, OpenAI or DeepSeek for cloud triage, or rules mode when you want everything offline.

git clone https://github.com/Zuri09/ReconRaptor.git
cd ReconRaptor
chmod +x install.sh reconraptor.sh
./install.sh                     # add --with-ollama for local AI
./reconraptor.sh -d example.com  # plain scan

# Optional AI triage:
./reconraptor.sh -d example.com --ai --ai-provider ollama
DEEPSEEK_API_KEY="sk-..." ./reconraptor.sh -d example.com --ai --ai-provider deepseek

Responsible use

Use it only where you have permission.

ReconRaptorAI is for assets you own or are explicitly authorized to test. Treat scanner and AI output as triage until you reproduce the issue manually.
